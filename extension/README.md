# vxNav 浏览器一键收藏扩展 (Chrome / Edge)

本目录为适用于 Google Chrome、Microsoft Edge、Brave 等基于 Chromium 内核浏览器的扩展程序源码。

## 安装指南

1. 打开浏览器，进入扩展管理页面：
   - Chrome 输入：`chrome://extensions/`
   - Edge 输入：`edge://extensions/`
2. 开启右上角的 **「开发者模式」 (Developer mode)** 开关。
3. 点击左上角的 **「加载已解压的扩展程序」 (Load unpacked)**。
4. 选择当前项目的 `extension` 文件夹即可完成安装！

## 使用方法

浏览任何网站时，点击浏览器右上角的扩展图标，点击 **「一键保存至导航站」**，即可自动弹出预填好的收藏卡片并完成智能抓取与保存！
